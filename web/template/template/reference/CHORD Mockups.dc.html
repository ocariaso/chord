1CHORD, modernized — mockup board

Assumptions I worked from: same information architecture and same scenario set as the current demo (landing → processing stages → results, plus failure states), Nocturne tokens throughout, and every control labelled in words rather than by shape. The wood cabinet and chrome plates are gone. There are now three result views on one full-width layout — 1c Mixer, 1d Console with faders and metering, and 1l Analog with labelled knobs and needle meters — earning the "studio" reading through instrumentation rather than decoration. Per-stem controls are the open question, so I built the four directions side by side (1f–1i) — pick one and I'll wire it into the real demo files. These are static mockups: nothing plays yet.
